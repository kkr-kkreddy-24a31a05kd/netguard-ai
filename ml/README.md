# Machine Learning Engine Directory

This directory contains the machine learning assets, preprocessing pipelines, training scripts, and serialized models for NetGuard AI.

## Directory Structure
- `data/`: Raw and processed dataset files (e.g., CICIDS2017 / UNSW-NB15 samples)
- `notebooks/`: Exploratory Data Analysis (EDA) and experimental feature modeling
- `pipelines/`: Reusable scikit-learn / XGBoost data preprocessing pipelines
- `models/`: Serialized model artifacts (`.joblib`) including metadata and metrics

*Note: Model training and inference will be implemented in Phase 4.*
